# Task Management Program

## Description

This is a simple JavaScript task program.

It allows users to:
- Add tasks
- display list all tasks
- Find a task by ID
- Mark tasks as completed
- Display completed tasks

## How to Run

1. Open the project in VS Code.
2. Open the terminal.
3. Run:by using a command line npm start

node task.js

4. The results will be displayed in the terminal.

## Example Usage

The program can be used to add, find, complete, and display tasks.

## as per requirement
It also checks for:
- Empty task titles
- Duplicate task IDs
- Unknown task IDs
